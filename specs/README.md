# Specifications

This directory holds **behavioral specifications** — descriptions of *what* target
software does, written from public, lawful sources. These are the "clean" inputs that the
implementation teams build from.

A spec describes behavior, formats, and protocols. A spec **never** contains:

- original/proprietary source code,
- decompiler or disassembler output,
- copied comments, identifiers, or code structure from a closed-source original.

Each non-obvious behavioral claim should cite its public source (a standard, published
docs, an observed input/output, a file-format reference). See
[`../docs/CLEANROOM.md`](../docs/CLEANROOM.md).
