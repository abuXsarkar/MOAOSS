Check the Content Credentials (C2PA provenance) of an image — right here, in your browser.

🔒 Your file never leaves this device. Verification runs entirely in your browser using a local WebAssembly engine. No upload, no servers, no tracking — works fully offline once the page has loaded.

Paste a recovery registry JSON (produced by durable/registry.py). When an image has no credentials, it is matched against this registry by perceptual fingerprint — computed in your browser, fully offline, no upload. Covers re-compression and scaling; cropping needs the CLI/server (ORB). Stored only in this browser.

Paste the PEM certificate(s) of the root authorities you trust. Signers are then cryptographically validated against your list — there is no central gatekeeper, and this stays fully offline. Stored only in this browser.

“Load test anchor” adds the C2PA test CA so you can see the Trusted ✓ state with a test-signed sample. It is not a production trust list — the test key is public. For real use, load the C2PA published list or your own roots.

Part of open-provenance — open-source, Apache-2.0. Built on the open C2PA standard. “Verified” means the provenance chain is intact, not that the depicted events are true.
