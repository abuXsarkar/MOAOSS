# Projects

Each subdirectory is a self-contained, clean-room open-source reimplementation built from
an approved specification in [`../specs/`](../specs/).

Every project must include a `README.md`, a `PROVENANCE.md` (contributors + team
assignment + attestations), and an OSI-approved `LICENSE`. See
[`../CONTRIBUTING.md`](../CONTRIBUTING.md) and
[`../governance/REVIEW.md`](../governance/REVIEW.md).

No project may contain proprietary source, decompiler output, or vendor assets.
