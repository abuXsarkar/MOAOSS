# Contributor Attestation

Every contributor to a `projects/` reimplementation must affirm the following before
their code is merged. Add your name to the project's `PROVENANCE.md` to record agreement.

> I affirm that:
>
> 1. The code I am contributing is my own original work (or lawfully licensed work I have
>    the right to contribute under this project's license).
> 2. I have **not** viewed, copied, decompiled, or adapted the source code of the
>    proprietary software this project reimplements.
> 3. I implemented solely from the approved behavioral specification in `specs/` and from
>    public, lawful sources.
> 4. I have not introduced any third-party code, assets, or trademarks that we lack the
>    rights to redistribute.
> 5. I understand that violating the clean-room firewall can compromise the entire
>    project and will result in my contribution being reverted.

If any of these is not true for you on a given project, you are disqualified from the
**implementation** side of that project. You may still be able to contribute on the
specification side — ask a maintainer.
